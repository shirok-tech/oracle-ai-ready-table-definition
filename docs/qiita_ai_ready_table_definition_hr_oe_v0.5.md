# ■ サンプル・ファイル

AI Ready Data を設計するためのテーブル定義書サンプルです。HR＋OE を 1 システムとして 1 つの Excel Book に収録し、テーブルごとの定義、Domain 定義、ER 図、Metadata 一覧を確認できます。COMMENT、Annotations、Domain も含みます。Blog の検証内容を一般化して再利用できるテンプレートです。
