## 収録内容

- 1 System／1 Book
- 1 Table／1 Sheet
- 1 Domain／1 Sheet
- Oracle Sample Schemas の HR および OE Sample Schema
- PK、UK、FK、CHECK、Index
- COMMENT、Annotations、Domain
- ER 図、Metadata 一覧、生成 DDL
